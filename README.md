# .github

The GitHub organisation profile for ratecla.im: `profile/README.md` is what
[github.com/Rateclaim](https://github.com/Rateclaim) shows.

`assets/org-banner.png` and `assets/org-avatar.png` are rendered in
[`Rateclaim/website`](https://github.com/Rateclaim/website) by
`tools/render-og.sh` (the banner is its `assets/readme-banner.png`). The avatar
is uploaded by hand at `github.com/organizations/Rateclaim/settings/profile`;
GitHub has no API for it.
